# 采购审批流程

## 1. 目的与背景
本流程规范采购审批的标准化操作，确保采购合规、高效。

## 2. 适用范围
适用于公司所有部门的采购审批场景。

## 3. 角色与职责

| 角色 | 职责描述 |
|------|----------|
| 申请人 | 发起采购申请，填写采购需求 |
| 部门负责人 | 审核采购需求的合理性 |
| 财务审批人 | 审核预算和资金安排 |
| 采购执行人 | 执行采购订单 |

## 4. 流程活动描述

### 4.1 提交采购申请
**执行角色**: 申请人  
**输入**: 采购需求  
**输出**: 采购申请单  
**描述**: 申请人填写采购需求，包括物品规格、数量、预算等

### 4.2 部门审批
**执行角色**: 部门负责人  
**输入**: 采购申请单  
**输出**: 审批意见  
**描述**: 部门负责人审核采购需求的合理性和必要性

### 4.3 财务审批
**执行角色**: 财务审批人  
**输入**: 部门审批通过的单据  
**输出**: 预算审批结果  
**描述**: 财务审批人审核预算情况

### 4.4 执行采购
**执行角色**: 采购执行人  
**输入**: 审批完成的采购单  
**输出**: 采购订单  
**描述**: 执行采购流程

## 5. 风险识别与控制

| 风险点 | 控制措施 | KCP |
|--------|----------|-----|
| 采购审批权限滥用 | 分级审批制度 | 是 |
| 预算超支风险 | 财务双重审核 | 是 |
| 供应商选择不当 | 供应商比价机制 | 否 |

## 6. 绩效指标

| 指标名称 | 目标值 | 计算方式 |
|----------|--------|----------|
| 采购审批时效 | ≤24小时 | 提交到审批完成时长 |
| 预算偏差率 | ≤5% | 实际金额与预算差额比例 |
